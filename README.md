# 歌语 · 外文歌逐句学习

面向手机浏览器的本地优先学习原型。首页为 Mrs. GREEN APPLE《ライラック》的歌名学习卡；尚未内置完整歌词或原唱音频。另有明确标注的日语、英语、韩语原创示例。

## 使用

运行 `node server.mjs`，电脑访问 http://127.0.0.1:4173 。手机使用部署后的 HTTPS 链接。麦克风需要 HTTPS 或 localhost 安全上下文。

点击「先体验日语原创示例」可以查看完整的平假名、词义、用法和整句翻译。正常朗读使用设备 SpeechSynthesis，需要安装对应语言的系统语音。示例旋律为钢琴音频，不是人声演唱。

学习真实歌曲时，点击「添加第一句歌词」，手动填写歌词、读音、整句翻译和词义。注音格式：`明日[あした] へ[へ] 歩こう[あるこう]`。每行词义格式：`词语 | 读音 | 中文词义 | 用法 | 例句 | 例句翻译`。也可以从「我的歌单」导入 JSON，格式参见 dist/example-song.json。

导入本机歌曲音频，在音频播放器中找到一句的起点和终点，保存时间段，再使用「歌曲片段」播放、变速或循环。歌曲人声来自用户导入的文件。

歌词资料、收藏、已学状态存于 localStorage；歌曲音频与麦克风录音存于 IndexedDB。没有账号同步、后台上传或自动生成翻译/平假名。切换句子、歌曲、页面或后台时会停止播放和保存当前录音。单次录音最长 2 分钟，可在练唱录音页回听、下载、删除。清除浏览器数据会删除本地资料，应导出学习资料和下载录音。

## 检查

`node --check dist/app.js` 和 `node --test tests/core.test.mjs`：脚本语法、三语示例注音/词义完整性、音频段边界和资料导入校验。有 npm 的环境也可以运行 `npm run check`。

本版没有自动翻译、自动平假名、自动对齐、真人逐句演唱合成或音准评分；这些需要后续语言/语音服务以及歌曲资料接入。设备 TTS 是自然朗读，与原唱唱法分开。
